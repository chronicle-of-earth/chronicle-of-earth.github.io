Milestones

Roadmap

Milestones from data foundation to global coverage, each with an exit criterion that must be met before the next begins.

  1. M0 · In progress

    Data foundation

    A typed schema with JSON Schema export, semantic checks, date matching, conflict-preserving queries, correction chains and deterministic static compilation. A historical data standard governs the next revision: identity continuity, precise evidence scope, spatial roles, observations and coverage.

    Exit criterion Reviewed examples exercise the first map layers, migrations are documented, and validators prevent demonstrated failure modes.

  2. M1 · Experiment exists

    Globe and timeline

    A static globe-to-village atlas with a calendar-scale timeline, evidence dossiers and partial-coverage states. Historical borders, offline support and performance certification remain outstanding.

    Exit criterion Orbit, zoom and picking; dated dossiers; discrete timeline transitions; uncertainty treatment; an HTML fallback; measured interaction performance on desktop and mobile.

  3. M2

    First curated historical slice

    A bounded regional and temporal slice with documented source and geometry rights — several meaningful changes rather than a broad map with sparse annotations. Facts and geometry reviewed independently; a coverage matrix and attribution manifest published.

    Exit criterion Every visible fact traces to evidence, historical boundaries are supported for the displayed dates, competing views remain inspectable, and missing coverage is unmistakable.

  4. M3

    Installable preview

    A static application shell with immutable, versioned data packs, offline behaviour and reproducible shared views — with no dedicated backend for browsing.

    Exit criterion A shared URL reproduces a view; downloaded packs work offline; deployment and rollback are repeatable.

  5. M4

    Coverage expansion

    Incremental ingestion, entity resolution, reviewer queues and partitioning by geography and time. Expansion toward 1900–2026 globally, then earlier human history.

    Exit criterion New sources integrate without rewriting the core model, provenance survives publication, and performance stays within measured budgets.
